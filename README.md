# تطبيق مانجا

قارئ مانجا ومانهوا ومانها يعمل في المتصفح، ويقدر ينثبت كتطبيق على الجوال (PWA).

## المميزات
- استكشاف وبحث مع فلتر النوع واللغة (عربي / English)
- صفحة العمل: الوصف، الفصول، التعليقات
- المكتبة والسجل ومتابعة القراءة
- إدارة المواقع
- وضع فاتح وداكن تلقائي
- المصدر المدمج: [MangaDex](https://mangadex.org)

## التشغيل على GitHub Pages
1. ارفع كل الملفات في مستودع جديد.
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. افتح الرابط الذي يظهر (`https://USERNAME.github.io/REPO/`).
4. على الجوال: قائمة المتصفح ← **إضافة إلى الشاشة الرئيسية**.

## ملاحظات
- المواقع المضافة يدويًا تُفتح في المتصفح، لأن المتصفحات تمنع قراءة محتوى مواقع أخرى مباشرة.
- المكتبة والسجل والتعليقات محفوظة على جهازك فقط.
- التطبيق يعرض ما توفره MangaDex، ولا يستضيف أي محتوى.
